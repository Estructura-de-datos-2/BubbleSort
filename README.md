# Ejercicio de Ordenamiento por Intercambio (Bubble Sort)

## Descripción
Este proyecto consiste en implementar el algoritmo Bubble Sort utilizando Java, con el propósito de ordenar un arreglo de números de menor a mayor mediante comparaciones e intercambios.

## Archivos
- `Burbuja.java`: Código fuente del algoritmo.
- `Compilacion y ejecucion.png`: Evidencia del programa funcionando.
- `U2ACT1 Ejercicio de Ordenamiento por Intercambio con Tarjetas.pdf`: Instrucciones de la actividad.

## Funcionamiento
El algoritmo compara dos números consecutivos y, si el primero es mayor que el segundo, intercambia sus posiciones. Este proceso se repite hasta ordenar todos los elementos.

## Ejecución

Compilar:

javac Burbuja.java


Ejecutar:

java Burbuja
